# FlashGroup

Prototype thương mại điện tử mua gom theo khu vực.

## Chạy trong Antigravity

```bash
npm install
npm run dev
```

Sau đó mở địa chỉ Vite hiển thị trong Terminal (thường là http://localhost:5173).

## Demo chính

1. Mở deal Dâu Đà Lạt đang ở 19/20.
2. Bấm tham gia.
3. Hệ thống mở khóa giá 89.000đ.
4. Phí ship chia sẻ = 60.000 / 20 = 3.000đ.
5. Checkout tổng = 92.000đ.
6. Thanh toán demo và nhận mã QR.
